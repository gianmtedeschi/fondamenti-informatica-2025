Material for the exercise sessions of *Fondamenti di Informatica* (082746). Includes exercises with their solutions in C.

| 03 | Loops and `switch` |
| 04 | Arrays |
| 05 | Strings and matrices |
| 06 | `typedef` and `struct` |
| 07 | Functions |
| 08 | Linked lists |
| 09 | Files and `argc`/`argv` |
